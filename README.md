# Social-Media-Web-Application-Backend-System

Developed a command-line-based social media platform simulating core functionalities of modern social network, including user registration, login, post creation, likes, comments, private messaging, and privacy management.
Implemented an administrative module for monitoring user activity, moderating reports, suspending accounts, and generating engagement analytics.
Designed the application using a layered architecture separating UI, service, and data access layers for modularity and maintainability.
Handled databases operations with JDBC and MySQL, ensuring referential integrity through foreign key constraints.
Focused on scalability, clean code, and adherence to best practices in software design.
Technology's used as Core Java, Maven, JDBC, MySQL and Console-Based UI.
